# crY

crY is the mathematically oriented branch of MeSH’lAng. Its purpose is to express operations and compositions that can guide software architecture and code generation.

The name **crY** was chosen for **crystallization**. Ideas from crystal structure and the study of crystals served as a design model for the mathematically oriented language. This explains its naming and architectural inspiration; the operative definitions belong to its versioned language profile. The later dRy line grew out of this work. See [the language-name lineage](../concepts/names.md#language-names-and-capitalization).

Where dRy emphasizes semantic orientation between agents, crY emphasizes the operative structure of a construction: what acts, what it acts on, how elements compose and how the resulting structure is unfolded.

## Architecture as an interpretable specification

A useful architectural expression can distinguish structure, function and interfaces. An agent can unfold that expression into modules, operations and connections, then compare the implementation with the originating specification.

The [Webstuhl case study](../case-studies/webstuhl.md) introduces this workflow through a small architectural source.

## Definition and implementation

crY has a versioned development history. An operator's reading belongs to its particular language profile. A mathematical label, a formal definition, an executable implementation and a verified property are distinct parts of a specification.

This public draft introduces the construction principle. It does not reproduce the full mathematical operator table or declare different historical profiles equivalent. It also does not announce a released crY language server.

## Tooling

A language server can provide completion, syntax diagnostics and profile-bound definitions to editors or agents. The public concept and the complete machine-readable language profile can have different distribution terms.
