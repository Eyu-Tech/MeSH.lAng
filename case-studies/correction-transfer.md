# A corrected decision reaches a later agent

This page is a sanitised description of an internal development experiment completed on 31 October 2026. Full private primers, tool binaries and original response archives are not bundled here. It is an internally documented technical case, not an independently reproduced public benchmark.

## The intended loop

An earlier agent attached a contribution to goal revision G1@1. A later review introduced a counterexample and accepted G1@2. A successor needed to recover the original relation, recognise why it was superseded, use the revised relation and retain an unrelated contribution under its separate goal. One missing relation had to remain unresolved.

The tested sequence was:

1. Preserve the earlier agent's original response, file operation and resulting artifact as separate records.
2. Resolve historical and current source records through Geotopie. Webstuhl supplied source-bound candidate matches; the reviewer determined the goal relation.
3. Bind the revised context to a registered selective tensor-cluster address.
4. Let a later CLI agent choose that address from an address catalogue. A project-local hook delivered the selected payload before its next substantive response.
5. Observe the later agent perform its own changed file operation while retaining foreign-goal and unresolved boundaries.

The technical chain was independently checked in that dedicated CLI/project-hook scope. It demonstrates an implemented route from preserved correction to received context and a changed subsequent action.

## What this does not isolate

The original reviewer expectation was read too early by the implementation roles. Blinding therefore failed. Explicit review, supplied task facts, conventional prose, language priming and delivery mechanisms were combined. The case does not isolate the contribution of a dRy chain, prove a general cross-provider invariant or establish global desktop operation.

A later sHieNtAmE development run worked toward isolated local-agent execution. It established productive local text inference and parts of resource enforcement; its 1.5B agent did not complete the constrained code workcase. The run was stopped by the operator on 1 November 2026. The larger-model workcase, full isolation checks, revision export and automatic Geotopie context comparison remained unfinished. It is not a completed constitution or language-effect benchmark.

The public [handoff demonstration](../examples/public-fragment/README.md) offers an independently tryable, much smaller relation-transfer task. It does not reproduce the private C9 infrastructure experiment.
