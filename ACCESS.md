MeSH’lAng is a public entry point for exploring semantic space addressing and language-guided architecture with an agent.

## Use the public material

Start with [the guided entry](START-HERE.md). This edition, including moQ’eX, is offered under CC BY 4.0 as stated in [LICENSE.md](LICENSE.md). Commercial use of that publicly licensed material does not require a separate paid agreement.

The [public dRy handoff fragment](examples/public-fragment/README.md) includes every definition used by its expressions, two cases, participant instructions and separate evaluation materials. It needs no private tooling. Readers can run a fresh sender/recipient exercise and record the result using the supplied template.

## Discuss a private implementation

An inquiry can concern a concrete agent workflow, its process-stability problem and the environment in which it runs. Useful starting information includes the model/provider, an example handoff or recurring error, the intended outcome and the available integration points.

A scoped engagement can cover workflow analysis, a measured pilot, version-bound private teaching/profile material, integration and training. Deliverables, supported versions, use rights, fees and maintenance are agreed for that engagement. This page does not promise a ready-to-download full product or a guaranteed improvement.

Complete private dRy/crY profiles, withheld tables and LSP implementations are outside this publication. A separately supplied profile may expose definitions and syntax through a language server or another integration; completion, hover information and diagnostics are possible surfaces.

Bry is described as a conceived/explored Bengali-script line, with no language profile, primer or benchmark package supplied in this edition. A production crY LSP and complete crY operator table are not released here. LamutikA remains a private originating language. Geotopie and the surrounding runtime are described only where needed to explain applications.

Any commercial agreement covers identified private materials, access or services. It does not charge for permission already granted by CC BY or claim exclusive control over the public ideas.

## Evidence for a pilot discussion

The [public handoff comparison](research/public-comparison-20261101.md) records 16/16 fully successful handoffs in the dRy-plus-gloss sender condition of that limited study. It is an inspectable starting point for discussion, not a promise of 100% process fidelity in another workflow. A customer pilot needs its own task, comparison and agreed success criteria.
